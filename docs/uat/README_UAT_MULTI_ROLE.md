## Cara Pakai Singkat

- Isi identitas penguji.
- Eksekusi setiap test case sesuai urutan.
- Isi kolom Hasil Aktual, Status, Nilai, dan Catatan.
- Hitung rekap PASS/FAIL/BLOCKED.
- Lengkapi tabel isu dan sign-off.

## Standar Kelulusan (Saran)

- Kasus kritikal: 100% PASS.
- Kasus non-kritikal: minimal 95% PASS.
- Tidak ada defect severity Critical yang belum terselesaikan.
